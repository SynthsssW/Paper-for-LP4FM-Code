# Clean figure set

Regenerated by `scripts/09_clean_figures.py`. Same data and same claims as the
originals in `paper/figs/`, redrawn with one consistent condition palette,
seaborn styling, direct labels, **10 pt type throughout**, and no in-figure
footer captions (put the caption in the LaTeX `\caption{}`). Vector PDF is the
deliverable; a PNG preview is written alongside. The originals in `paper/figs/`
are left in place; nothing here overwrites them.
