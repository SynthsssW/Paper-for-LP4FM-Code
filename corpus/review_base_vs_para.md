# Corpus — manual review: base vs paraphrase

100 problems. For each, the original (`base`) and the answer-preserving
paraphrase (`para`). The paraphrase must state the same problem with the same
quantities and the same answer. Mark anything that does not.

Every quantity appears in both by construction, and all mechanical checks pass
(arithmetic re-executed, character spans verified). What remains is meaning.
