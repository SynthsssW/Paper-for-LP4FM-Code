# transformers is a FLOOR, not an exact pin, and that is deliberate.
# DESIGN.md §A.2: "the open-weights frontier churned monthly through 2026" and

# that existed when this file was written. An exact pin here is the failure mode
# where the model loads as the wrong architecture or not at all at 2am. Verify
# with AutoConfig.from_pretrained before the run (configs/model.yaml step 3);
# if the pinned floor does not know the architecture, install from git.
transformers>=4.51.0

numpy==2.2.6
scipy==1.15.3

PyYAML==6.0.2
